9/27周日

苏州 · 夜游古城

只住一晚，把时间给夜景和第二天早上的一碗头汤面。

  1. 傍晚

    平江路 高赞推荐

    河边石板路，天黑挂灯后最出片。猫的天空之城书店可以寄一张"慢递"明信片给自己。

  2. 晚上

    山塘街 · 通贵桥 高赞推荐

    七里山塘夜景的经典机位在通贵桥一带，可以坐一段夜游船。

    评论：节假日很挤，21 点后人少一些。

  3. 白天

    拙政园 / 苏州博物馆 可选

    如果白天就到苏州可以去。两处都要提前实名预约，国庆经常约满。

吃什么

  • 苏式汤面，早上吃"头汤面"
  • 生煎、蟹壳黄
  • 苏帮菜：松鼠桂鱼、响油鳝糊
  • 鸡头米桂花酒酿，9 月底还赶得上新鲜鸡头米

评论避雷

  • 观前街被吐槽商业化，路过即可
  • 山塘街拉客的游船报价先问清
  • 28 日要赶长途，早饭后尽早出发
9/28周一

苏州 → 鄱阳 → 南昌

赶路日。下午到鄱阳吃一顿湖鲜，晚上进南昌住下。

  1. 上午

    出发去鄱阳

    自驾约 550 km。坐高铁的话可以走杭黄线接昌景黄线，到鄱阳站，车次以 12306 为准。

  2. 傍晚

    鄱阳湖国家湿地公园 可选

    秋天水位下降，湖床露出大片草洲，笔记里叫它"鄱阳湖草原"，适合看日落。

    候鸟要等到 11 月以后，这次看不到大群候鸟，别抱这个期待。

  3. 晚饭

    鄱阳湖鲜 高赞推荐

    认准湖鱼：鱼头、鳜鱼、银鱼炒蛋、湖虾、螺蛳。10 月初也开始有鄱阳湖大闸蟹了。

  4. 晚上

    去南昌，约 2 小时

    住八一广场、万寿宫或红谷滩秋水广场附近，第二天去梅岭、晚上看滕王阁都方便。

点菜提醒

  • 江西菜普遍重辣，评论区公认"微辣也很辣"
  • 不吃辣就直接说"不放辣"

评论避雷

  • 湖鲜按斤称的先问单价再下锅
  • 湖边路段晚上偏黑，夜里开车注意
9/29周二

南昌 · 梅岭 + 滕王阁夜景

白天进山避暑，傍晚回城看赣江日落和亮灯。

  1. 早餐

    南昌拌粉 + 瓦罐汤 高赞推荐

    南昌人的标准早餐，街边小店就行，配一个白糖糕。

  2. 上午

    梅岭 · 洪崖丹井 高赞推荐

    市区西北约 40 分钟车程。峡谷溪水和小瀑布，传说是中国乐律的发源地，游览 1–1.5 小时。

  3. 下午

    梅岭盘山公路 / 狮子峰 可选

    天气好就沿盘山路兜一圈，山上能看到南昌城区。中午在山里吃农家菜，竹笋和土鸡。

    评论：景点分散，没车很不方便；期待别太高，胜在清凉安静。

  4. 傍晚

    滕王阁 高赞推荐

    笔记几乎都建议傍晚进，登顶看赣江日落，等天黑亮灯。"落霞与孤鹜齐飞"就在这里。

  5. 晚上

    秋水广场音乐喷泉 / 万寿宫街区

    喷泉在滕王阁对岸，演出一般在晚上，场次以当天公告为准。想吃夜宵就去万寿宫。

吃什么

  • 南昌炒粉、米粉蒸肉
  • 三杯鸡（江西本地菜）
  • 酱鸭、鸭脖
  • 白糖糕、麻圆

评论避雷

  • 滕王阁白天去被说"一般"，夜景才值
  • 八一广场附近停车难，打车更省事
9/30周三

万年神农宫 → 景德镇

上午钻溶洞，下午到景德镇，晚上直接去陶溪川。

  1. 早上

    南昌出发，约 2 小时到万年

  2. 上午

    神农宫溶洞 高赞推荐

    喀斯特溶洞，钟乳石规模大，灯光做得很出片，游览约 1.5 小时。

    洞里凉又湿滑，带件薄外套，穿防滑的鞋。

  3. 顺路

    仙人洞与吊桶环遗址 可选

    世界上最早的栽培稻和陶器遗存之一，对考古有兴趣可以顺路看。中午吃一碗万年贡米饭。

  4. 下午

    去景德镇，约 1.5 小时

    住陶溪川或陶阳里附近，两晚都方便步行逛夜市。

  5. 晚上

    陶溪川 高赞推荐

    老瓷厂改造的园区，景德镇收藏量最高的地方。夜里的创意市集全是年轻手作人摆摊，节假日开放时间看官方公告。

景德镇吃什么

  • 冷粉（早餐当地人的最爱）
  • 碱水粑、饺子粑
  • 油条包麻糍
  • 瓷泥煨鸡，要提前订

评论避雷

  • 陶溪川市集周末和节假日人极多，早点去
  • 路边"大师作品"溢价严重，别冲动
10/1周四

景德镇 · 看窑、拉坯、淘瓷

一天把"瓷都"的看、玩、买串起来。

  1. 上午

    御窑博物馆 + 御窑厂遗址 高赞推荐

    砖拱造型的博物馆本身就是拍照点，馆内是明清官窑瓷片和复原器。需要实名预约。

  2. 上午

    陶阳里历史街区

    就在御窑旁边，老街、窑址、里弄，边走边吃。

  3. 下午

    古窑民俗博览区 高赞推荐

    能看到柴窑烧制、手工拉坯、青花绘制的全过程，可以现场体验拉坯。带小朋友的笔记评价最高。

  4. 下午

    三宝国际陶艺村 可选

    山谷里的陶艺村，工作室和咖啡馆，人少安静。想躲人流选这里。

  5. 晚上

    陶溪川 / 雕塑瓷厂

    再逛一次夜市。雕塑瓷厂的小店以创作者作品为主，价格比景区实在。

买瓷器

  • 杯子、小盘这类小件性价比最高
  • 大件让店家打包快递，多数包邮
  • 中国陶瓷博物馆免费，也要预约

评论避雷

  • "厂家直销""大师亲笔"多是话术
  • 国庆当天各馆预约紧，提前抢
10/2周五

婺源 · 篁岭晒秋

秋天的婺源就看篁岭。国庆人最多，赢在早起。

  1. 6:30

    景德镇出发，约 1.5 小时

    路过月亮湾可以停车拍几张，就在路边。

  2. 上午

    篁岭 高赞推荐

    家家屋顶晒红辣椒、黄菊花、稻谷，就是"晒秋"。天街、观景台、梯田都在这。

    笔记共识：8 点前到。索道排队太久的话可以徒步上山，大约 40 分钟。

  3. 下午

    汪口 / 晓起 可选

    都在篁岭附近。汪口是临水古村，晓起有成片古樟树，比热门村人少。

  4. 晚上

    住江湾镇或婺源县城

    第二天要开约 3 小时去龙虎山，住县城出发更顺。

吃什么

  • 荷包红鲤鱼
  • 粉蒸肉、粉蒸菜
  • 酒糟鱼、笋干烧肉
  • 篁岭天街的晒秋小吃

评论避雷

  • 李坑被吐槽商业化，时间少就跳过
  • 石城的红枫要到 11 月下旬，现在去太早
  • 江岭是春天看油菜花的，秋天不必去
10/3周六

鹰潭 · 龙虎山

丹霞山水加道教祖庭，竹筏是整座山的精华。

  1. 早上

    婺源出发，约 3 小时

  2. 上午

    泸溪河竹筏 高赞推荐

    坐竹筏顺流看丹霞峰林，几乎所有笔记都说这是龙虎山最值的部分。

    国庆排队久，到了先取号。

  3. 中午

    仙水岩 · 升棺表演 高赞推荐

    现场演示古人怎样把棺木吊进崖洞，每天有固定场次，到景区先看时间再排竹筏。

  4. 下午

    天师府 · 上清古镇

    道教正一派祖庭，古镇沿河，节奏慢，适合下午散步。

  5. 下午

    象鼻山 可选

    一块像大象喝水的岩石，要爬一段台阶，体力留给庐山的话可以不去。

  6. 晚上

    住龙虎山景区附近

    明早直接出发去庐山。

吃什么

  • 上清豆腐
  • 泸溪河鱼
  • 天师板栗烧土鸡

评论避雷

  • 门票、竹筏、表演分开计费，买前看清套票内容
  • 竹筏没有遮挡，带帽子和防晒
  • 下雨时竹筏可能停航
10/4周日

庐山 · 上山 + 经典步道

笔记最统一的建议：住在山上的牯岭镇，两天足够。

  1. 上午

    龙虎山 → 庐山，约 3 小时

    国庆期间庐山常常限制私家车上山，要在山下换乘景区观光车。出发前看庐山官方公众号的交通通知。

  2. 下午

    如琴湖 → 花径 → 锦绣谷 → 仙人洞 高赞推荐

    庐山收藏量最高的一条步行线，大多是平路和下坡，全程约 2–3 小时。锦绣谷的崖边步道最出片。

  3. 晚上

    牯岭街 + 庐山恋电影院 高赞推荐

    电影院每天放映 1980 年的《庐山恋》，几十年没停过，看一场很有意思。

吃什么

  • 庐山"三石"：石鱼炒蛋、石耳炖鸡、石鸡（养殖）
  • 庐山云雾茶

评论避雷

  • 山上比山下低 6–7℃，一定带外套
  • 山上物价偏高，住宿要早订
  • 雾大就看不到远景，别硬等
10/5周一

庐山 · 日出 + 瀑布

按体力二选一：三叠泉累但评价最高，五老峰轻松视野好。

  1. 清晨

    含鄱口日出 可选

    天晴才值得去，云海要看运气。前一晚看好天气预报再定。

  2. 上午

    三叠泉 高赞推荐

    "不到三叠泉，不算庐山客"。瀑布分三级落下，但往返台阶非常多，要 3 小时左右。

    评论：膝盖不好慎选，下山后腿会酸好几天。

  3. 上午

    或 五老峰

    五座山峰并排，登高能看到鄱阳湖，比三叠泉轻松很多。

  4. 下午

    美庐别墅 + 庐山会议旧址

    都在牯岭附近，室内参观为主，下雨也能去。

体力分配

  • 早上看日出的话，上午选五老峰
  • 三叠泉建议一早去，避开中午人流

评论避雷

  • 景区观光车高峰排队长，留出等车时间
  • 山路湿滑，穿防滑鞋
10/6周二

下山 · 返程

庐山到苏州约 650 km，节后返程车多，尽量上午就出发。

  1. 上午

    白鹿洞书院 可选

    在山脚，朱熹讲学的地方，林子里很安静，逛 1 小时左右。

  2. 上午

    或 秀峰 可选

    李白"飞流直下三千尺"写的就是这一带的瀑布，想补个庐山瀑布可以来。

  3. 中午后

    开车回家

    中途在服务区多休息，两人轮换开。

雨天备选

苏州苏州博物馆本馆，建筑和展品都能看半天
南昌梅岭换成江西省博物馆，或八大山人纪念馆；滕王阁雨夜照样亮灯
万年神农宫本来就在洞里，不受影响
景德镇御窑博物馆、中国陶瓷博物馆、古窑的室内作坊、找家店做拉坯体验
婺源小雨里的徽派村子像水墨画，评论反而说好看；大雨就少走山路
龙虎山竹筏可能停航，改去天师府和上清古镇
庐山美庐、庐山会议旧址、庐山博物馆、庐山恋电影院都在室内
